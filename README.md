#### Svar på följande frågor om git:
    Vad är skillnaden mellan git add och git commit?
        - git add = När man lägger till filerna i staging man har skapat i branchen på det projekt man jobbar med.
        - git commit = Då skapas en ny version av det lokala repot och det läggs till samt att man beksriver med kort text vad det är. 
    Varför använder man branches istället för att jobba direkt i main?
        - I branches kan man ha den lokalt i datorn och kan ändra/ skapa innehåll utan att störa main, originalet. Då har man möjlighet att testa och se vad man har gjort om det behövs.
    Vad händer rent praktiskt när man gör en merge?
        - Då lägger man ihop den del av branchen man har jobbat med i main och kombinerar filerna. 
    Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?
        - Att pusha till GitHub lägger man till ändringar i repositoryn och publiceringen i Netlify är färdiga webbplatsen man skapar.
    Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?
        - Då skapar man en ny textfil i rotmappen och döper den till .gitignore där listar man filnamn och mappar och tas inte med i repot men finns kvar i rotmappen. Det kan t.ex. vara känsliga uppgifter/infomration, loggfiler
